# ambassador-system-

## Problem Statement
Campus Ambassador (CA) programs often fail due to:
- Lack of structure and clarity
- No proper tracking of performance
- Low engagement
- No personalized feedback for ambassadors

most systes do not understand their ambssadors psychologically 
## my Solution
Smart Ambassador is a python based system that:

 Analyzes ambassador performance  
 Understands psychological state (mood) 
 Evaluates GitHub activity  
 Provides personalized recommendations  
 Motivates users with appreciation  

 It acts like a personal tracking with advic and their future 


## Key Features

## Performance Scoring
- Calculates a score out of 100 based on:
  - Tasks completed
  - Consistency
  - GitHub activity

---

## Mood Detection (Psychological Insight)
- Detects user mood from text input:
  - Motivated
  - Demotivated
  - Neutral
## Personality Classification
- Identifies working style:
  - Hustler 
  - Strategist 
  - Balanced 
  - Inactive 
##  GitHub Profile Evaluation
- Analyzes number of repositories
- Provides feedback:
  - Strong / Average / Needs Improvement
## Smart Recommendations
- Suggests tasks based on:
  - Personality
  - Mood
## Future Prediction
- Predicts:
  - Growth 
  - Stability
  - Risk 
## Appreciation System
- Encourages users with positive feedback
- Improves motivation and engagement
## How It Works

User provides:
- Tasks completed
- Consistency score
- GitHub repositories
- Mood input

System processes:
- Behavioral analysis
- Rule-based intelligence
- Generates personalized report
